How the AI works

The agent runs by itself, every game day. Each round it does four things:

  1. Observe — checks every plant: water, health, pests, ripeness, season and tomorrow's weather.
  2. Think — decides what to do. With a key, a real AI model reads the garden and writes the plan. Without one, built-in gardening rules decide.
  3. Act — uses its tools only: water, feed, shade, spray, harvest, clear, refill, plant.
  4. Learn — if a plant wilts, it remembers to water that kind earlier next time.

The autonomy setting decides what it may do without asking you.
